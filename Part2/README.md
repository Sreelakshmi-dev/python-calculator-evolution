Part 2 Enhancing Calculator Functionality
Focuses on improving functionality, managing data, handling errors, and making the calculator more interactive 
and reliable.
Each level introduces new concepts and demonstrates how an existing program can be improved step by step.

Python Concepts Explored:

* Functions and reusable code
* Dictionaries and lambda expressions
* Loops and conditional statements
* Exception handling with try-except
* Lists and tuples for managing data
* Calculation history
* memory management
* Input validation and error prevention
* Working with Python modules

Project Objectives:

1. Improve code readability and organisation.
2. Introduce additional calculator features.
3. Handle invalid inputs without crashing.
4. Store and retrieve previous calculations.
5. Explore different approaches to solving programming problems.
6. Develop debugging and problem-solving skills.
