#class_method
Level 9: OOP and Modular Programming

This level reorganises the calculator using object-oriented programming (OOP). It demonstrates classes and objects, instance attributes and methods, `self`, and encapsulation by grouping related data and behaviour.

The program separates calculation logic, menu options, memory management and history into modules. It also demonstrates importing modules, creating aliases with `as`, and passing objects as arguments to functions.

The `if __name__ == '__main__':` guard calls `main()` when the file is run directly, allowing it to be imported without automatically starting the calculator.

Memory, calculation chaining, history and CSV storage from earlier levels are retained.
#How to Save and run:
All required Python files are included. Save them in the same folder and run the main program file. The calculator will display a menu; follow the prompts to perform calculations.
