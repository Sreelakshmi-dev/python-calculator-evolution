Python Calculator Series – Part 1

Levels 1–4: Python Basics

This is the first part of a 12-level Python calculator project. Each level introduces new concepts and improves the calculator.

Topics Covered
* Variables and arithmetic operations
* User input and output
* Functions
* Conditional statements and match-case
* Error handling
* Lambda functions
* Lists, tuples and dictionaries
